# Sentiment Dashboard - AI-Powered Investment Intelligence

## 🎯 項目概述

一個基於 AI 的投資情緒分析儀表板，整合社交媒體熱點、新聞情緒和市場數據，幫助投資者發現潛在機會。

## 🏗️ 架構

```
sentiment-dashboard/
├── frontend/          # Stitch UI 前端
├── backend/           # FastAPI 後端
├── agents/            # LangGraph AI Agent 團隊
├── data_sources/      # 數據源集成
└── docs/             # 文檔
```

## 🚀 核心功能

### 1. 情緒儀表盤
- 實時熱點話題監控
- 多維度情緒分析
- 投資機會識別
- 科技感 UI 界面

### 2. AI Agent 團隊
- 任務拆解與意圖理解
- 多 Agent 協作分析
- 智能調研與建議
- 基於 LangGraph + Minimax

## 📊 數據源

- **NewsAPI**: 全球新聞熱點
- **Reddit JSON API**: 社交媒體情緒
- **CoinGecko**: 加密貨幣數據

## 🔧 技術棧

- **Frontend**: Stitch (科技感 UI)
- **Backend**: FastAPI + Python
- **AI**: LangGraph + Minimax
- **Data**: Real-time streaming
